🔐 Password Generator

A simple and responsive Password Generator built using HTML, CSS, and JavaScript. The application allows users to generate random passwords with customizable length and character types.

🚀 Features
🔢 Choose password length using a slider
🔤 Include lowercase letters
🔠 Include uppercase letters
🔢 Include numbers
🔣 Include special symbols
🎲 Generate random passwords
📋 Copy password to clipboard with one click
📱 Responsive and user-friendly interface
🛠️ Technologies Used
HTML5 – Structure of the application
CSS3 – Styling and responsive design
JavaScript – Password generation and DOM manipulation

⚙️ How It Works
Select the required password length using the slider.
Choose the character types you want:
Lowercase letters
Uppercase letters
Numbers
Symbols
Click the Generate Password button.
A random password will be generated based on your selections.
Click the Copy icon to copy the password to your clipboard.
